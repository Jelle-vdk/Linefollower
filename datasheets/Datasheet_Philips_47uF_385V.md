# Datasheet / Specificaties – Philips Elektrolytische Condensator (47 µF – 385 V)

## Algemene Informatie
* **Component:** Axiale aluminium elektrolytische condensator (gepolariseerd)
* **Fabrikant:** Philips (*Made in Holland*, jaren '70)
* **Reeks:** Philips 016 / 017 / 118 serie
* **Moderne referentie / opvolger:** Vishay BCcomponents 021 ASM (`MAL2021...`)
* **Toepassing in dit project:** Ontkoppelings- / buffercondensator over de voedingsrail om spanningsdippen en motorruis op te vangen.

---

## Elektrische & Fysische Specificaties

| Eigenschap | Waarde |
| :--- | :--- |
| **Nominale capaciteit ($C_R$)** | 47 µF |
| **Capaciteitstolerantie** | ± 20% |
| **Nominale spanning ($U_R$)** | 385 V DC |
| **Type behuizing** | Axiaal (cilindrisch, blauwe isolatiemantel) |
| **Polariteit** | Gepolariseerd (min-pool aangeduid met zwarte band/inkeping) |
| **Bedrijfstemperatuur** | -40 °C tot +85 °C |
